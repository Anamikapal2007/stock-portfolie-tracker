# stock-portfolie-tracker
A simple Python program that calculates the total investment value of a stock portfolio using predefined stock prices.
<br>
## Features
- Takes stock names and quantities as input.
- Uses a dictionary to store stock prices.
- Calculates total investment value.
- Saves the result to a text file.
<br>
## Technologies Used
- Python
- Dictionary
- File Handling
- Basic Arithmetic
<br>
## How to Run
- Run the Python file.
- Enter the number of stocks.
- Enter stock names and quantities.
- View the total investment value.
